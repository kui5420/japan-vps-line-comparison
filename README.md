## 三條線路的差別，決定了價格差三倍

DMIT 把東京機房拆成三個網路等級，命名很直白：T1 是 Tier 1 標準網路，Pro 是 Premium，EB 是 Eyeball。

T1 的線路描述是「國際優化 + 中國大陸普通線路」。走普通國際出口，不繞路也不優先，中國大陸訪問在晚高峰會受出口壅塞影響。它的價值在流量與價格：TYO.T1.MINI 給到 8TB/月、10Gbps 峰值，月付 21.90 美元。

Pro 走三網 CN2 GIA 直連，峰值帶寬 1Gbps。CN2 GIA 是中國電信的優質國際線路，回程不走普通 163 骨幹，晚高峰的穩定性是它貴的原因。流量給得克制，入門檔只有 500GB/月。

EB 走三網 CMIN2 直連，峰值帶寬 1Gbps 到 4Gbps。CMIN2 是中國移動的國際線路，對移動用戶友好，這條線的流量比 Pro 寬鬆，入門檔 1TB/月。

三個等級的硬體寫法一致，核心數、記憶體、硬碟容量的對應關係相同，差別落在線路與流量額度上。同樣是 1 核 1GB 20GB SSD，T1 月付 6.90 美元，Pro 21.90 美元，EB 25.90 美元。

## 同樣 21.90 美元，買 500GB 的 CN2 GIA 還是 8TB 的普通線路

判斷看用途。你的使用者會在晚上八點到十一點打開網站，而且他們在中國大陸，Pro 的錢值得花；流量用來跑備份、鏡像、圖床、下載，對即時速度不敏感，T1 那 8TB 用得上。

再往下一檔看，TYO.T1.TINY 月付 6.90 美元給 2TB，是 Pro.TINY 的四倍流量、三分之一的價格。入門建站如果只是先跑起來看看效果，這台比 Pro 更適合當第一台。

小檔位還有一個容易被忽略的組合：TYO.T1.WEE 年付 36.90 美元，配置和 T1.TINY 相同，流量砍半、超額速度 50Mbps，但總價只有 T1.TINY 年付 76.90 美元的一半。願意一次付一年、用量又不大的話，這是全場最便宜的入口。

## 下單前要自己確認的五件事

這幾項在公開套餐頁上沒有統一寫清楚，開一張工單問明白，比事後爭論省事。

1. **流量口徑**：單向還是雙向計費。T1 系列標明了超額後降速（WEE 50Mbps，其餘 100Mbps）但可繼續使用；Pro 與 EB 的超額處理沒有公開說明，是用超停機還是限速，值得先問。
2. **IP 屬性**：機房原生 IP 還是廣播 IP。要做日區串流解鎖或平台帳號註冊，這一項直接影響成敗，比價格重要。
3. **退款條件**：公開套餐頁沒有統一的退款天數說明，售後走工單。想留退路就先月付，把一個月的費用當試用成本。
4. **付款方式與幣種**：結賬頁會顯示可用管道與最終扣款幣種，信用卡的匯率轉換由發卡行決定，別只看美元標價。
5. **帶寬口徑**：頁面上的 1Gbps、4Gbps、10Gbps 是峰值數字，共享還是保證、保證到什麼程度，一併問清。

## 東京、香港、洛杉磯怎麼排

DMIT 三個機房都分 T1 / Pro / EB 三級，日本在延遲與價格之間取中間位。香港延遲最低、單位帶寬最貴；洛杉磯價格最低、延遲最高。目標訪客在日本、韓國、台灣，或需要一個亞太落點，東京比另外兩個合適。純做中國大陸中轉、對延遲極敏感的用途，香港更直接，成本也更高。

延遲數字方面，第三方測評給日本東京到華南的通用區間是 50–80ms，華北約 80–110ms。這是機房層面的參考值，不是 DMIT 的實測數據，實際結果取決於你所在地區、運營商和線路等級。T1 與 Pro、EB 的差別主要體現在晚高峰的抖動，不在 ping 值的絕對高低。

## 常見問題

**東京機房延遲多少？**
第三方測評的通用區間是華南 50–80ms、華北 80–110ms，實際看你所在地區與運營商。線路等級影響的是晚高峰穩定性，不是 ping 值的絕對高低。

**T1 會不會很慢？**
白天差別不大，晚高峰中國大陸出口壅塞時，T1 的抖動比 Pro、EB 明顯。它的補償是流量與價格，8TB 流量月付 21.90 美元這種配置在 Pro 系列裡不存在。

**流量用超了會斷網嗎？**
T1 系列標明超額後降速（50 或 100Mbps）繼續可用。Pro 與 EB 沒有公開說明，下單前問一句。

**能不能退款？**
公開套餐頁沒有統一的退款天數。想保留退路就先月付，或下單前開工單問清條件再付款。

**日本還是香港？**
訪客在東亞、需要大流量與較低單價，日本；只要最低延遲、預算充足，香港。

**月付還是年付？**
年付價基本等於月付乘十二，沒有折扣紅利。先月付測一個月，是這家定價結構下最合理的做法。
